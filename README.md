# Error-Log-Agent-Microservices

This application should enable an LLM to convert unstructured logs into actionable information for a monitoring and orchestration system such as n8n.

## Initialize and push the repository

```bash
git init
git add .
git commit -m "Initial commit - LLM Log Analyzer"
git branch -M main
git remote add origin https://github.com/alex81word/Error-Log-Agent-Microservices.git
git push -u origin main
```
